# Lista de Tareas en PHP

Una aplicación web simple para gestionar tareas, construida con PHP y MySQL.

## ¿Qué hace?
- Agregar tareas nuevas
- Marcar tareas como completadas
- Borrar tareas
- Todo se guarda en una base de datos MySQL

## Tecnologías usadas
- PHP
- MySQL
- HTML/CSS

## Cómo correrlo localmente
1. Instala XAMPP
2. Coloca esta carpeta dentro de `htdocs`
3. Crea la base de datos `mi_base_de_datos` con la tabla `tareas`
4. Abre `localhost/lista-de-tareas-php/lista.php`
